# ZRYX VD

**Zryx VD — Multi-feature script for Violence District**

The ultimate all-in-one script built to give you full control in *Violence District*. ESP, aimbot, auto-play features, movement boosts, and more — all packed into a clean, modern UI.

![Version](https://img.shields.io/badge/version-1.0.0-blue) ![Supported](https://img.shields.io/badge/supported%20executors-xeno%20%7C%20delta%20%7C%20solara%20%7C%20velocity-brightgreen)

</div>

## Features

### Combat
- **Aimbot** — auto-aim at enemies with adjustable strength
- **Aimlock** — lock your target while holding right click
- **Aim Part** — choose which body part to aim at
- **FOV** — custom aim field of view
- **Prediction** — lead your shots based on target movement
- **Killer** — kill all, auto attack, auto carry
- **Autoparry** — automatic perfect parry against killer attacks
- **Killer detection** — faces, range & cooldown control

### ESP
- Survivor ESP
- Killer ESP
- Generator ESP (with repair progress %)
- Pallet & Window ESP
- SCP ESP
- ESP Radius & status (name, distance, health)

### Survivor Utilities
- **Auto Skill Check** — perfect generator skill checks
- **Auto Wiggle** — escape killer carry automatically
- **Auto Flee Killer** — keep your distance from the killer
- **Fast Vault** & animation speed boost
- **God Mode** — stay alive no matter what

### Movement
- Walk speed value
- Custom jump power
- No Clip
- **Moonwalk** — custom keybind with spam speed & intensity
- Crosshair position & size

### Visual & Extra
- Graphics toggles (sun, ambient, clock)
- Morph avatar
- Camera zoom-out / FOV
- Emote player
- Fully customizable UI theme & save system

## Getting Started

1. **Supported executors:** Xeno, Delta, Solara, Velocity (keyless)
2. Copy the script from `zryxvd.lua`
3. Paste into your executor
4. Execute and press **Left Control** to toggle the menu
